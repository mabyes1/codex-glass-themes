# v2.0.0 — Token 飼料、魚魚搶食與額度觀測

發布日期：2026-10-23

Codex Glass Themes 的水族館現在會回應你在 Codex 裡的工作：本機新增的 token 用量會化成小代幣飼料，魚會搶，吃到不同模型的口味還會有不同表情。頂部額度快捷區也一起加入這版，工作時可以直接看剩餘額度。

- [Windows x64 安裝檔](https://github.com/mabyes1/codex-glass-themes/releases/download/v2.0.0/ChatGPT-Glass-Themes-Setup-2.0.0-win-x64.exe)
- [33 秒四格示範 MP4](https://github.com/mabyes1/codex-glass-themes/releases/download/v2.0.0/codex-glass-themes-v2.0.0-four-feeds.mp4)：1080 × 1350、H.264、24 FPS，無音訊。

影片直接錄製這版的 aquarium renderer，使用獨立 Chromium 測試場景。四格分別是 Astra、Sol、Terra、Luna，以手動試吃觸發真實的追逐、攝食與反應程式；沒有呼叫模型、沒有消耗 token，也沒有錄入聊天或帳號資料。

## 四種飼料

| 模型家族 | 飼料與反應 |
| --- | --- |
| Astra | 金色 token chips，🥹💖✨、金色光暈 |
| Sol | 淡藍色 token chips，😋💕 |
| Terra | 普通棕色 token chips，😑💭、輕輕抖動 |
| Luna | 可疑棕色 token chips，🤢🤮、變綠、吐出碎屑，幾秒後恢復 |

小顆粒帶有亮邊和 `‹›` 刻痕，會翻轉、慢慢下沉。以上口味是這個水族館的玩笑設定。

每顆最多吸引三隻附近的魚。第一隻把嘴靠近、開始吸入的魚吃到；其他魚往空掉的位置多滑一點，停頓後冒出 🥺💨，沿弧線回原本水深。銀龍的轉彎與加速較慢，偶爾搶輸或撲空。上仰保留魚身比例。

「佈景 → 水族館 → 手動試吃」可以選四種口味，一次六顆，不增加真實 token 計數。表情使用 35% 不透明度，陪伴工作時比較不搶眼。

## 額度觀測

頂部顯示 **5 小時剩餘百分比、每週剩餘百分比、重置券數量**。滑鼠移到百分比上可看恢復時間；點擊進入 Codex 原生用量區。重置券按鈕只開啟原生確認流程，不會自動使用重置券。

資料來自 Codex 自己的 query cache，跟著原生資料更新。介面寬度小於 620 px 時會隱藏快捷區；原生資料尚未就緒時顯示「—」。這段整合依賴 Codex 介面，官方改版後可能需要更新。

Token 飼料使用本機 session 的用量紀錄，與額度百分比是兩種不同計量。Token 計數從助手啟動後累積、重啟歸零，各模型每 10,000 tokens 換一顆；cached input 與 reasoning 不重複加算。[完整規則](../token-feeding.md)。

## 效能與驗證

魚數、24 FPS 上限、十二個游動姿態與搶食效果保留。優化改的是重複工作：不讀未變動的 session 內容、不解析無關工具輸出、用量未變不更新數字；重用小型 emoji／飼料貼圖，選魚只保留最近三名。

開發電腦上，閒置 token 檢查的五次取樣中位數由約 54 ms 降至 1.7 ms。這個比較的範圍是 token 檢查流程；畫面內容與 GPU 合成不同，不能直接換算為整個 Codex 的 CPU 或耗電改善。

- 37 項 Node 測試通過：計數、去重、分段寫入、閒置 I/O、手動試吃、搶食唯一勝者、落敗反應及快取釋放等。
- 42 個 Chromium 檢查通過：兩種 Windows 效果路徑、額度更新、恢復時間與原生重置確認等。原生橋接在此使用測試替代品。
- 13 項安裝器檢查通過：解包、部署、內附 Node／JS 語法、原生助手、套件查詢、衝突保護、別名恢復和移除；現有工作安裝保留。
- 真實 Codex renderer 已確認自動餵食、四種試吃、競爭與落敗、Luna 嘔吐。四格錄影也檢查四種口味均吃到、Luna 確實吐出碎屑。

完整登出／登入、一般冷啟動，以及另一台乾淨 Windows 10／11 電腦的完整安裝、啟動、移除，尚未完成實機驗收。
