# Milky Way / 銀河星海

Generated with the built-in `image_gen` tool for the Cosmos collection. The project asset is `packaging/payload/theme/assets/milky-way.png`. Stars, drifting dust and the occasional comet are animated separately in `cosmos.mjs`; the background is baked into a bounded canvas when loaded or resized.

以內建 `image_gen` 製作銀河底圖；星光、星塵與彗星由程式獨立繪製。

## Prompt

Create one cinematic deep-space background texture for a glass desktop app theme. Landscape 16:9. Elegant astronomical Milky Way seen from deep space, immense soft diagonal band of dusty blue-violet nebula from bottom left toward upper right, delicate pale silver and muted rose stardust, many tiny varied stars and a few subtle luminous points. Dark ink navy and near-black dominate, sophisticated natural filmic color, mysterious, ethereal and quietly awe-inspiring, no saturated neon. Dim spacious negative space in the middle and lower middle for readable foreground UI; strongest nebula structure near outer thirds. Soft dust clouds with intricate detail and depth. No planets, no black hole, no meteors or streaks (those will be animated in code), no foreground landscape, no text, no borders, no UI. This is a static background asset, not a screenshot or mockup. Save generated image to local file and return path.
